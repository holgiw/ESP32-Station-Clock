# Arduino IDE / arduino-cli / Visual Micro: Partitionsschemata fuer den ESP32-C6 und den ESP32-S2 von uhr4 (App 2,25 MB,
# Dateisystem 1,625 MB). Im Projektordner wirkt die Datei nicht - sie gehoert in den Ordner des ESP32-Cores (neben dessen
# boards.txt), die Tabellen uhr4_c6.csv und uhr4_s2.csv nach tools/partitions darin:
#   Windows: %LOCALAPPDATA%\Arduino15\packages\esp32\hardware\esp32\4.0.0\boards.local.txt und \tools\partitions\uhr4_c6.csv, uhr4_s2.csv
#   Linux:   ~/.arduino15/packages/esp32/hardware/esp32/4.0.0/boards.local.txt und /tools/partitions/uhr4_c6.csv, uhr4_s2.csv
#   macOS:   ~/Library/Arduino15/packages/esp32/hardware/esp32/4.0.0/boards.local.txt und /tools/partitions/uhr4_c6.csv, uhr4_s2.csv
# Danach die IDE neu starten und beim C6 unter Tools -> Partition Scheme "uhr4 C6 (2.25MB APP/1.6MB SPIFFS)" waehlen,
# beim S2 "uhr4 S2 (2.25MB APP/1.6MB SPIFFS)".
# Nach einem Core-Update (neuer Versionsordner) alle Dateien erneut kopieren. Andere Boards bleiben unberuehrt.
#
# Arduino IDE / arduino-cli / Visual Micro: partition schemes for uhr4's ESP32-C6 and ESP32-S2 (app 2.25 MB, file
# system 1.625 MB). In the project folder the file has no effect - it belongs in the ESP32 core's folder (next to its
# boards.txt), the tables uhr4_c6.csv and uhr4_s2.csv in tools/partitions inside it:
#   Windows: %LOCALAPPDATA%\Arduino15\packages\esp32\hardware\esp32\4.0.0\boards.local.txt and \tools\partitions\uhr4_c6.csv, uhr4_s2.csv
#   Linux:   ~/.arduino15/packages/esp32/hardware/esp32/4.0.0/boards.local.txt and /tools/partitions/uhr4_c6.csv, uhr4_s2.csv
#   macOS:   ~/Library/Arduino15/packages/esp32/hardware/esp32/4.0.0/boards.local.txt and /tools/partitions/uhr4_c6.csv, uhr4_s2.csv
# Then restart the IDE and choose Tools -> Partition Scheme "uhr4 C6 (2.25MB APP/1.6MB SPIFFS)" for the C6,
# "uhr4 S2 (2.25MB APP/1.6MB SPIFFS)" for the S2.
# Copy all files again after a core update (new version folder). Other boards stay untouched.
#
# upload.maximum_size = 0x240000 (App-Partition / app partition)

esp32c6.menu.PartitionScheme.uhr4_c6=uhr4 C6 (2.25MB APP/1.6MB SPIFFS)
esp32c6.menu.PartitionScheme.uhr4_c6.build.partitions=uhr4_c6
esp32c6.menu.PartitionScheme.uhr4_c6.upload.maximum_size=2359296

lolin_s2_pico.menu.PartitionScheme.uhr4_s2=uhr4 S2 (2.25MB APP/1.6MB SPIFFS)
lolin_s2_pico.menu.PartitionScheme.uhr4_s2.build.partitions=uhr4_s2
lolin_s2_pico.menu.PartitionScheme.uhr4_s2.upload.maximum_size=2359296
